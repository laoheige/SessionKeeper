# SessionKeeper

SessionKeeper 是一个 Chrome Manifest V3 扩展：定期在后台访问你已登录的网站，延续登录会话，避免 Cookie 过期后反复重新登录。

不注入脚本、不读取网页内容、不上传任何数据，所有配置和日志仅保存在本机。

## 功能

- 自动扫描浏览器已打开的 HTTP/HTTPS 网站，按域名去重
- 勾选需要保活的站点，未勾选的不执行
- 执行间隔 30–60 秒可自定义范围，每轮在区间内随机取值
- 页面加载后停留时长可自定义范围（0–300 秒），随机等待
- 并行后台标签页 1–10 个可调，默认 3 个
- 后台标签页打开即不抢占当前页面，完成后自动关闭
- 黑名单 / 白名单模式
- 本地保存最近 100 条运行日志，支持一键清空
- 底部按钮即总开关：开启立即执行一轮并启动定时，关闭停止一切
- 适配 MV3 Service Worker 休眠与恢复

## 安装使用

1. 下载 Release 中的 `sessionkeeper-v1.1.0.zip` 并解压（或克隆本仓库）
2. 打开 Chrome，进入 `chrome://extensions`
3. 右上角开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的文件夹
4. 点击工具栏中的 SessionKeeper 图标：
   - 在「控制台」勾选需要保活的站点
   - 点「开启保活」即可，之后按设定间隔自动运行

## 隐私与权限

- `tabs`：扫描已打开的标签页地址，用于生成站点列表
- `alarms` / `storage`：定时调度与本地保存设置、日志
- `webNavigation`：识别页面加载失败
- 主机权限（http/https）：在后台打开目标网站页面

扩展不收集、不上传任何数据；卸载扩展即删除全部本地数据。
